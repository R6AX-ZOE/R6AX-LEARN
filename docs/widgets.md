# 小组件内容

## 通用
    交互：长按或右键出现菜单，包括：不再显示/移动组件/编辑内容

## 1. 连胜组件
    组件内容：连续打卡的天数；
    大小：正方形，1：1；
    可编辑的内容：不可编辑

## 2. 笔记组件
    组件内容：具体的笔记目录（在目录中继续键入：{{dir}}）；
    大小：长方形，1：2；
    交互：点击后进入；
    可编辑的内容：绑定的目录（默认为上一次记录的笔记或智能推荐）；
    数量：1~3

## 3. 教ai以复习组件
    组件内容：具体的session（继续教学会话：{{session}}）；
    大小：长方形，1：2；
    交互：点击后进入；
    可编辑的内容：不可编辑；
    数量：未完成的session全部显示

## 4. 继续练习组件
    组件内容：具体的session（继续练习：{{session}}）；
    大小：正方形，1：1；
    可编辑的内容：不可编辑；
    数量：未完成的session全部显示

## 5. 新练习组件
    组件内容：开始练习：{{topic}}；
    大小：长方形，1：2；
    可编辑的内容：文本框，允许用户修改主题
