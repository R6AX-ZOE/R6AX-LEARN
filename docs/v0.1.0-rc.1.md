# v0.1.0-rc.1 更新记录

对比基线：v0.1.0-beta.2（commit 5ce1af9 之后的全部改动）
日期：2026-09-03

## 体积精简：移除 RAG / 语义检索重依赖（本次重点）

- `pyproject.toml`：移除 `sentence-transformers`、`numpy` 两个本地 RAG 依赖，默认安装不再引入 torch 系重依赖。
- 向量检索全面改为**纯 Python 实现**：
  - `app/services/embedding_service.py` 内置确定性词法向量（MD5 哈希 n-gram → 384 维），相同文本恒得到相同向量；
  - 余弦相似度计算改为纯 Python（不再需要 numpy）；
  - 语义模型（sentence-transformers + all-MiniLM-L6-v2）降级为**可选增强**：需自行 `pip install sentence-transformers` 并运行 `scripts/download_embedding_model.py` 预下载模型后才启用。
- 运行时**永不下载模型**：模型缺失时静默降级为词法向量，RAG 检索 / 虚拟图检索（`search_virtual_graphs_rag` 等接口与工具）保持不变、仍可用，仅语义效果略弱。
- `Dockerfile`：不再预装 CPU 版 torch、不再在构建期预下载 embedding 模型，镜像体积显著减小。
- 更新说明：安装后本地占用的依赖体积由约 950 MB（torch / numpy / sentence-transformers 一整套）降至几乎为零；语义检索体积仅为可选增量（模型约 90 MB）。

## 安装 / 构建 / 部署

- Docker：改用预编译 CPU wheel、跳过 apt 安装；`.dockerignore` 忽略本地 wheelhouse。
- `install.sh` / `install.bat` / `bootstrap.sh` / `bootstrap.bat`：提示统一为英文、错误处理加固、PORT 解析修正。
- 安装过程自动初始化数据库（新增 `scripts/init_db.py`），Windows 端补充 bootstrap 说明。

## 功能修复与改进

- **Teaching**：AI 流式回复与 HTTP 请求生命周期解耦（新增 `app/services/teaching_streams.py`），刷新 / 重连后可持续接收 AI 回复，不再丢回复。
- **Practice**：修复空会话显示 "question 1/0 all done" 的问题；自动触发题目生成并上报后台任务错误；新增生成中等待页。
- **Embedding 下载脚本**：官方源（huggingface.co）不可达时自动回退镜像 `hf-mirror.com`；仍失败时支持手动指定 `HF_ENDPOINT`。
