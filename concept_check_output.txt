Learning Concept #1:
  Name: "正弦函数"
  Description: "在直角三角形中，正弦函数定义为对边与斜边的比值，记作 sin(θ)。"

Learning Concept #2:
  Name: "余弦函数"
  Description: "在直角三角形中，余弦函数定义为邻边与斜边的比值，记作 cos(θ)。"

Learning Concept #3:
  Name: "正切函数"
  Description: "在直角三角形中，正切函数定义为对边与邻边的比值，记作 tan(θ)，也等于 sin(θ)/cos(θ)。"

Learning Concept #4:
  Name: "余切函数"
  Description: "在直角三角形中，余切函数定义为邻边与对边的比值，记作 cot(θ)，也等于 cos(θ)/sin(θ)。"

Learning Concept #5:
  Name: "正割函数"
  Description: "正割函数定义为余弦函数的倒数，记作 sec(θ) = 1/cos(θ)。"
